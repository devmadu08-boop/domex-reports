# DOMEX dashboard artwork

`domex-islandwide-hero.jpg` is the locally bundled hero and campaign background for the islandwide dashboard. It was generated with the built-in ImageGen tool and encoded as JPEG at quality 88 for a smaller download (approximately 366 KB).

Prompt: Create an ultra-wide cinematic, photorealistic golden-hour Sri Lankan landscape with a winding coastal road, tropical hills and a Sigiriya-like rock. A burgundy DOMEX truck drives away near center-right. A courier storefront, a delivery motorcycle and parcels appear on the far right. Leave the left third airy and cream for HTML copy. Use warm cream, burgundy, forest green and honey gold. Physical signage reads DOMEX. No interface, charts, cards, headlines, floating maps or watermark.

All dashboard labels, controls, statistics, and charts are real React components; the image contains only scenery.
